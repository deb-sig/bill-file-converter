# 交通银行借记卡

## 支持范围

| `--type` | 适用场景 |
| --- | --- |
| `bocom_debit` | 交通银行 App 导出的借记卡交易明细 PDF |

## 下载账单 PDF

常见路径：

1. 打开交通银行 App，搜索“交易明细”。
2. 点击底部“导出交易明细”，选择电子版。
3. 选择卡号并设置自定义时间范围。
4. 设置账单格式并开启需要的明细字段，填写接收邮箱地址。
5. 从邮箱下载 PDF 文件。

请导出电子版 PDF，不要用截图替代。

## 转换命令

```bash
go run ./cmd/bill-file-converter convert ./bocom-debit.pdf \
  --type bocom_debit \
  --config config.yaml \
  --output output
```

## 输入注意事项

- 交易明细每条交易都有递增序号，转换以序号列识别真实交易行。
- 页眉、页脚和“打印完毕”等内容不会进入 CSV。

## 输出核对

CSV 表头应为：

```text
序号,交易日期,交易时间,交易类型,借贷,交易金额,余额,对方账号,对方户名,交易地点,摘要
```

如果表头被识别为中英文混排，输出仍会统一为中文标准表头。

# 招商银行借记卡

## 支持范围

| `--type` | 适用场景 |
| --- | --- |
| `cmb_debit` | 招商银行 App “流水打印”导出的完整版借记卡流水 PDF |

> [!NOTE]
> 当前只支持包含“客户摘要”的完整版导出；旧版简化导出会被拒绝。该账单类型会移除水印图片浮层，需要系统安装 Ghostscript。

## 下载账单 PDF

常见路径：

1. 打开招商银行 App。
2. 搜索“流水打印”。
3. 切换到“高级筛选”。
4. 选择卡号、起始日期和结束日期。
5. 设置账单格式：
   - “展示摘要类型”选择“全部”。
   - “展示交易对手信息”选择“开启”。
   - “展示完整卡号”选择“开启”。
   - “展示收入及支出汇总金额”选择“关闭”。
   - “交易币种”选择“全部”。
   - “金额区间”选择“关闭”。
   - “交易类型”选择“全部”。
   - “仅展示活期户流水”选择“关闭”。
6. 填写接收邮箱地址并确认导出。
7. 从邮箱下载 PDF 文件。

## 转换命令

```bash
go run ./cmd/bill-file-converter convert ./cmb-debit.pdf \
  --type cmb_debit \
  --config config.yaml \
  --output output
```

## 输入注意事项

- 必须使用完整版导出，确保表格包含“客户摘要”列。
- 如果提示找不到 `gs`，请先安装 Ghostscript。
- PDF 本身是文本型，但水印图片可能影响 VLM 表格识别，因此转换前会做图片移除预处理。

## 输出核对

CSV 表头应为：

```text
记账日期,货币,交易金额,联机余额,交易摘要,对手信息,客户摘要
```

如果输出缺少“客户摘要”，说明输入可能不是当前支持的完整版导出。

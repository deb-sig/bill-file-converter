# 中国农业银行借记卡

## 支持范围

| `--type` | 适用场景 |
| --- | --- |
| `abc_debit` | 中国农业银行 App 导出的借记卡交易明细 PDF |

> [!NOTE]
> 该账单类型会在解析前移除 PDF 图片浮层或印章，因此需要系统安装 Ghostscript。

## 下载账单 PDF

常见路径：

1. 打开中国农业银行 App，进入首页“我的账户”。
2. 选择借记卡，进入“明细查询”。
3. 点击“明细查询”页面右上角导出按钮。
4. 填写账户、币种、时间范围和接收邮箱。
5. 提交后，从邮箱下载银行发送的 PDF 附件。

银行 App 页面可能随版本变化。关键要求是导出交易明细 PDF，而不是截图或页面总览。

## 转换命令

```bash
go run ./cmd/bill-file-converter convert ./abc-debit.pdf \
  --type abc_debit \
  --config config.yaml \
  --output output
```

## 输入注意事项

- PDF 中的交易日期通常是 `YYYYMMDD` 紧凑格式。
- 部分交易行的交易时间可能为空，转换以交易日期列识别真实交易行。
- 如果提示找不到 `gs`，请先安装 Ghostscript。

## 输出核对

CSV 表头应为：

```text
交易日期,交易时间,交易摘要,交易金额,本次余额,对手信息,日志号,交易渠道,交易附言
```

重点核对行数、交易金额和连续重复交易段。行数异常时参考 [排障指南](../troubleshooting.md)。

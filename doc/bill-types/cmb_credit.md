# 招商银行信用卡

## 支持范围

| `--type` | 适用场景 |
| --- | --- |
| `cmb_credit` | 招商银行信用卡账单 PDF |

## 下载账单 PDF

常见路径：

1. 打开掌上生活 App。
2. 搜索“账单补寄”或进入账单相关页面。
3. 选择目标账单周期。
4. 提交申请并确认接收邮箱。
5. 从邮箱下载导出的 PDF 文件。

请使用账单 PDF，不要使用截图。若邮件正文直接展示账单，请先打印/导出为 PDF。

## 转换命令

```bash
go run ./cmd/bill-file-converter convert ./cmb-credit.pdf \
  --type cmb_credit \
  --config config.yaml \
  --output output
```

## 输入注意事项

- 还款、退款、消费等分组行不会作为交易行输出。
- 还款行的交易日可能为空，转换以记账日列识别真实交易行。

## 输出核对

CSV 表头应为：

```text
交易日,记账日,交易摘要,人民币金额,卡号末四位,交易地金额
```

如果 MinerU 把中英文表头合并到同一个单元格，输出仍会统一为中文标准表头。
